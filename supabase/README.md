# Supabase Database Structure (Prepared for Phase 2)

This directory is reserved for FoundDex's PostgreSQL database migrations, Row-Level Security (RLS) policies, and storage bucket setup.

No database connection or credentials are required in **Phase 1**.

In **Phase 2**, we will:
1. Create a Supabase project and add credentials to `.env.local`.
2. Add SQL migration files under `supabase/migrations/`.
3. Generate TypeScript types into `src/lib/supabase/types.ts`.
